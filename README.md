# Grandprix Online — ระบบ e-commerce สินค้าพรีเมี่ยม

ร้านค้าออนไลน์สำหรับสินค้าพรีเมี่ยมของการแข่งขัน Grandprix
พร้อมระบบหลังบ้านสำหรับจัดการแบนเนอร์ สินค้า สมาชิก และดูยอดขาย

🔗 **เว็บไซต์:** https://nidss.github.io/gps/

---

## ⚠️ ข้อควรทราบก่อนใช้งาน

เว็บนี้ deploy เป็น **static site** บน GitHub Pages จึง **ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูลจริง**

- ข้อมูลทั้งหมด (สินค้า ตะกร้า สมาชิก ออเดอร์) เก็บอยู่ใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง
- ข้อมูลไม่ sync ข้ามอุปกรณ์ และจะหายถ้าล้างข้อมูลเบราว์เซอร์
- ระบบล็อกอินและสิทธิ์ผู้ดูแลเป็นการสาธิตระดับ UI เท่านั้น **ไม่ปลอดภัยพอสำหรับใช้งานจริง**
- ถ้าต้องการใช้งานจริง ต้องต่อ backend + ระบบชำระเงินจริง
  (โครงสร้าง state แยกไว้ใน `src/store/AppStore.tsx` เพื่อให้สลับไปเรียก API ได้ไม่ยาก)

## 🛠 เทคโนโลยี

- **Vite 7** + **React 19** + **TypeScript**
- **Tailwind CSS 4** (ชุดสีแบรนด์: `#dd3333` และ `#333946`)
- **React Router 7** แบบ HashRouter — ทำให้รีเฟรชหน้าลึก ๆ บน GitHub Pages ไม่เจอ 404
- ไม่มี dependency สำหรับ UI หรือกราฟ — ไอคอนและกราฟเขียนเป็น SVG เองทั้งหมด

### ดึงสินค้าจากร้านเดิมเข้ามา (scraper)

ถ้าต้องการย้ายแคตตาล็อกจากร้านเดิมเข้ามาแทนข้อมูลตัวอย่าง:

```bash
node scripts/scrape-products.mjs "https://www.rodlifestore.com/category/286464"
```

รองรับแพลตฟอร์ม **ReadyPlanet** (ที่ rodlifestore.com ใช้) เป็นพิเศษ —
อ่านราคาจากการ์ดสินค้าในหน้าหมวดหมู่ เพราะหน้าสินค้าเรนเดอร์ราคาด้วย JavaScript

สคริปต์จะอ่านหน้าหมวดหมู่ → ไล่เข้าหน้าสินค้าทีละชิ้น → ดาวน์โหลดรูปลง
`public/images/products/` → แล้วเขียนทับ `src/lib/products.data.ts`
(สำรองไฟล์เดิมไว้เป็น `.bak` ให้อัตโนมัติ)

| ตัวเลือก | ความหมาย |
|---|---|
| `--limit=20` | ดึงมาไม่เกินกี่ชิ้น (ค่าเริ่มต้น 40) |
| `--category="ชื่อ"` | บังคับชื่อหมวดหมู่ |
| `--delay=800` | หน่วงเวลาระหว่างคำขอ (มิลลิวินาที) |
| `--no-images` | ไม่โหลดรูป ใช้ URL จากร้านเดิมตรง ๆ |
| `--dry-run` | แสดงผลลัพธ์อย่างเดียว ไม่เขียนไฟล์ |
| `--debug` | พิมพ์ลิงก์และ JSON-LD ที่หาเจอ ใช้ตอนปรับ selector |

วิธีอ่านข้อมูล เรียงตามลำดับที่ลอง: **JSON-LD** (`schema.org/Product`) →
**OpenGraph meta** → **CSS selector** ที่พบบ่อยในร้านไทย
ตรวจจับราคาลดจากราคาที่ถูกขีดฆ่า (`<del>`, `.price-old`, `.original-price` ฯลฯ) ให้อัตโนมัติ

หลังรันเสร็จให้ `npm run build` เพื่อตรวจว่าไม่มีปัญหา แล้ว commit

#### ถ้าเครื่องที่รันสคริปต์เข้าเว็บร้านไม่ได้

ใช้ `scripts/browser-extract.js` แทน — เปิดหน้าหมวดหมู่ในเบราว์เซอร์
กด F12 → แท็บ Console → วางโค้ดทั้งไฟล์ → กด Enter
สคริปต์จะไล่อ่านหน้าสินค้าให้ แล้วคัดลอกผลลัพธ์เป็น JSON ลงคลิปบอร์ด

> สคริปต์ยิงคำขอทีละรายการแบบมีหน่วงเวลา และอ่านเฉพาะหน้าเว็บสาธารณะ
> ควรใช้กับร้านที่คุณมีสิทธิ์ในเนื้อหาและรูปภาพเท่านั้น

### เปลี่ยนรูปสินค้าเป็นรูปจริง

รูปสินค้าปัจจุบันเป็น placeholder สีแบรนด์ที่สร้างจาก `scripts/gen-images.mjs`
เปลี่ยนเป็นรูปจริงได้โดยวางไฟล์ทับใน `public/images/products/`
หรือแก้ที่อยู่รูปผ่านหน้า **จัดการสินค้า** ในระบบหลังบ้านได้เลย
