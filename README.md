# Grandprix Online - ระบบ e-commerce สินค้าพรีเมี่ยม

ร้านค้าออนไลน์สำหรับสินค้าพรีเมี่ยมของการแข่งขัน Grandprix
พร้อมระบบหลังบ้านสำหรับจัดการแบนเนอร์ หน้าแรก สินค้า หมวดหมู่ สมาชิก แชทลูกค้า และดูยอดขาย

🔗 **เว็บไซต์:** https://nidss.github.io/gpshop/

> ถ้าเข้ามาแก้โค้ดต่อ อ่าน [`CLAUDE.md`](./CLAUDE.md) ด้วย -
> รวมกับดักเฉพาะของโปรเจกต์นี้ที่เคยทำให้เกิดบั๊กจริงมาแล้ว

## ⚠️ ข้อควรทราบก่อนใช้งาน

เว็บนี้ deploy เป็น **static site** บน GitHub Pages จึง **ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูลจริง**

- ข้อมูลทั้งหมด (สินค้า ตะกร้า สมาชิก ออเดอร์ แชท) เก็บอยู่ใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง
- **แชทลูกค้า** จึงคุยกันได้เฉพาะในเบราว์เซอร์เดียวกัน (เช่น เปิดหน้าร้านกับหลังบ้านคนละแท็บ) ลูกค้าจริงกับแอดมินจริงข้ามเครื่องคุยกันไม่ได้
- ข้อมูลไม่ sync ข้ามอุปกรณ์ และจะหายถ้าล้างข้อมูลเบราว์เซอร์
- ระบบล็อกอินและสิทธิ์ผู้ดูแลเป็นการสาธิตระดับ UI เท่านั้น **ไม่ปลอดภัยพอสำหรับใช้งานจริง**
- ถ้าต้องการใช้งานจริง ต้องต่อ backend + ระบบชำระเงินจริง
  (โครงสร้าง state แยกไว้ใน `src/store/AppStore.tsx` เพื่อให้สลับไปเรียก API ได้ไม่ยาก)

## 📦 สินค้าในระบบ

ตอนนี้มีสินค้า **11 รายการ** ดึงมาจากหมวด ROD ของ rodlifestore.com
(`src/lib/products.data.ts`) - **ชื่อสินค้า ราคาเต็ม ราคาลด และรูปภาพเป็นข้อมูลจริงของร้าน**
รูปทั้ง 14 ไฟล์ถูกเก็บไว้ในโปรเจกต์แล้วที่ `public/images/products/`

ข้อมูลส่วนที่ยัง **ไม่ใช่ของจริง** และควรแก้ก่อนเปิดขาย:

| รายการ | สถานะตอนนี้ |
|---|---|
| จำนวนสต็อก | ตั้งไว้ 50 เท่ากันทุกชิ้น |
| รหัสสินค้า (SKU) | 10 จาก 11 ชิ้นสร้างจากเลขในลิงก์ (ขึ้นต้น `ROD-`) ไม่ใช่ SKU จริง |
| คำบรรยาย | ชิ้นแรกเป็นข้อความจริงจากร้าน ที่เหลือเขียนขึ้นใหม่จากชื่อและรูป ยังไม่ได้ตรวจกับสเปกสินค้าจริง |

ทั้งสามอย่างนี้ **แก้ผ่านหน้าจัดการสินค้าในระบบหลังบ้านได้เลย ไม่ต้องแก้โค้ด**

### หน้าร้าน

| หน้า | เส้นทาง | รายละเอียด |

| ชำระเงินสำเร็จ | `#/checkout/success/:id` | เลขที่คำสั่งซื้อ สรุปรายการ และข้อมูลใบกำกับภาษี |
| สมัครสมาชิก | `#/register` | ตรวจสอบข้อมูลครบถ้วนและกันอีเมลซ้ำ |

Navbar มีครบทั้ง **การแจ้งเตือน** (พร้อมตัวนับที่ยังไม่อ่าน) **เมนูสมาชิก** และ **ตะกร้าสินค้า**

ปุ่ม **แชท** มุมขวาล่างทุกหน้า - ใช้ได้ทั้งสมาชิกและผู้ไม่ได้ล็อกอิน (กรอกชื่อก่อน)
มีปุ่มคำถามด่วน บอทตอบคำถามที่พบบ่อยให้ทันที ส่วนเรื่องอื่นรอแอดมินตอบจากหลังบ้าน

กดปุ่มเพิ่มลงตะกร้าแล้ว **รูปสินค้าจะย่อส่วนโค้งวิ่งไปลงที่ไอคอนตะกร้าแล้วตะกร้าเด้งรับ**
เพื่อให้เห็นชัดว่าของเข้าตะกร้าแล้วจริง ถ้าผู้ใช้ตั้งค่าเครื่องให้ลดการเคลื่อนไหวไว้
(`prefers-reduced-motion`) จะไม่มีอะไรวิ่งข้ามจอ แต่ยังเห็นตะกร้าขยายพร้อมวงแหวนเรืองแทน

## 🛠 เทคโนโลยี

- **Vite 7** + **React 19** + **TypeScript 5.9**
- **Tailwind CSS 4** (ชุดสีแบรนด์: `#dd3333` และ `#333946`)
- **React Router 7** แบบ HashRouter - ทำให้รีเฟรชหน้าลึก ๆ บน GitHub Pages ไม่เจอ 404
- ไม่มี dependency สำหรับ UI หรือกราฟ - ไอคอนและกราฟเขียนเป็น SVG เองทั้งหมด

### ⚠️ แก้ข้อมูลสินค้าแล้วต้องบวก `CATALOG_VERSION`

ข้อมูลตั้งต้นถูกเขียนลง `localStorage` **แค่ครั้งแรก** ที่ผู้ใช้เข้าเว็บ

ถ้าแก้ `src/lib/products.data.ts` หรือ `src/lib/seed.ts` แล้วลืมบวกเลข `CATALOG_VERSION`
ใน `src/store/AppStore.tsx` **คนที่เคยเข้าเว็บมาก่อนจะเห็นข้อมูลชุดเก่าค้างตลอดไป**
แม้ deploy ใหม่เรียบร้อยแล้วก็ตาม

พอบวกเลขแล้ว ระบบจะเขียนทับเฉพาะสินค้า แบนเนอร์ คูปอง และล้างตะกร้า
ส่วนบัญชีสมาชิกกับประวัติออเดอร์ยังอยู่ครบ

## 🔄 ดึงสินค้าจากร้านเดิมเข้ามา (scraper)

ถ้าต้องการย้ายแคตตาล็อกจากร้านเดิมเข้ามาแทนข้อมูลปัจจุบัน:

```bash
node scripts/scrape-products.mjs "https://www.rodlifestore.com/category/286464"
```

รองรับแพลตฟอร์ม **ReadyPlanet** (ที่ rodlifestore.com ใช้) เป็นพิเศษ -
อ่านราคาจากการ์ดสินค้าในหน้าหมวดหมู่ เพราะหน้าสินค้าเรนเดอร์ราคาด้วย JavaScript

สคริปต์จะอ่านหน้าหมวดหมู่ → ไล่เข้าหน้าสินค้าทีละชิ้น → ดาวน์โหลดรูปลง
`public/images/products/` → แล้วเขียนทับ `src/lib/products.data.ts`
(สำรองไฟล์เดิมไว้เป็น `.bak` ให้อัตโนมัติ)

| ตัวเลือก | ความหมาย |
|---|---|
| `--limit=20` | ดึงมาไม่เกินกี่ชิ้น (ค่าเริ่มต้น 40) |
| `--category="ชื่อ"` | บังคับชื่อหมวดหมู่ |
| `--delay=800` | หน่วงเวลาระหว่างคำขอ (มิลลิวินาที) |
| `--no-images` | ไม่โหลดรูป ใช้ URL จากร้านเดิมตรง ๆ |
| `--dry-run` | แสดงผลลัพธ์อย่างเดียว ไม่เขียนไฟล์ |
| `--debug` | พิมพ์ลิงก์และ JSON-LD ที่หาเจอ ใช้ตอนปรับ selector |

วิธีอ่านข้อมูล เรียงตามลำดับที่ลอง: **JSON-LD** (`schema.org/Product`) →
**OpenGraph meta** → **CSS selector** ที่พบบ่อยในร้านไทย
ตรวจจับราคาลดจากราคาที่ถูกขีดฆ่า (`<del>`, `.price-old`, `.original-price` ฯลฯ) ให้อัตโนมัติ

หลังรันเสร็จให้ `npm run build` เพื่อตรวจว่าไม่มีปัญหา
**บวก `CATALOG_VERSION`** ตามหัวข้อด้านบน แล้วค่อย commit

### ถ้าเครื่องที่รันสคริปต์เข้าเว็บร้านไม่ได้

ใช้ `scripts/browser-extract.js` แทน - เปิดหน้าหมวดหมู่ในเบราว์เซอร์
กด F12 → แท็บ Console → วางโค้ดทั้งไฟล์ → กด Enter
ผลลัพธ์จะถูกคัดลอกเป็น JSON ลงคลิปบอร์ดให้อัตโนมัติ (ราว 4 วินาทีต่อสินค้าหนึ่งชิ้น)

สคริปต์เปิดหน้าสินค้าแต่ละหน้าใน iframe แล้ว **รอให้ JavaScript ของร้านเรนเดอร์เสร็จ**
ก่อนค่อยอ่าน จึงได้คำบรรยาย รหัสสินค้า และตัวเลือกสินค้า ซึ่งไม่มีอยู่ใน HTML ดิบ
โดยใช้วิธีวนเช็กเนื้อหาแทนการรออีเวนต์ `load` - สคริปต์ analytics ที่ช้าตัวเดียว
จึงไม่ทำให้ทั้งงานค้าง

> สคริปต์ยิงคำขอทีละรายการแบบมีหน่วงเวลา และอ่านเฉพาะหน้าเว็บสาธารณะ
> ควรใช้กับร้านที่คุณมีสิทธิ์ในเนื้อหาและรูปภาพเท่านั้น

## 🖼 จัดการรูปสินค้า

รูปสินค้าทั้งหมดถูกเก็บไว้ในโปรเจกต์แล้ว **ไม่ได้เรียกจาก CDN ภายนอก**
เพราะ CDN ของร้านเดิมกัน hotlink ทำให้รูปไม่ขึ้นเมื่อเรียกจากโดเมนอื่น

เปลี่ยนรูปได้ 3 วิธี:

1. **แก้ผ่านหน้าจัดการสินค้า** ในระบบหลังบ้าน - ใส่ที่อยู่รูปใหม่ได้เลย ง่ายที่สุด
2. **วางไฟล์ทับ** ใน `public/images/products/` แล้ว commit
3. **ดึงรูปจาก URL ภายนอกที่ยังค้างอยู่ใน `products.data.ts` เข้ามาเก็บ**

```bash
node scripts/download-images.mjs              # รันซ้ำได้ รูปที่มีแล้วจะถูกข้าม
node scripts/download-images.mjs --dry-run    # ดูว่าจะโหลดอะไรบ้างก่อน
```

ถ้าเครื่องที่รันออกอินเทอร์เน็ตไม่ได้ ให้สั่งผ่าน GitHub แทน:
เข้าแท็บ **Actions → ดึงรูปสินค้าเข้าโปรเจกต์ → Run workflow**
(`.github/workflows/fetch-product-images.yml`) - runner ของ GitHub จะโหลดรูป
แก้ `products.data.ts` ตรวจว่า build ผ่าน แล้ว commit กลับเข้า repo ให้เอง

ไฟล์ `.svg` ชุดเดิมใน `public/images/products/` เป็น placeholder สีแบรนด์
ที่สร้างจาก `scripts/gen-images.mjs` ตอนยังไม่มีรูปจริง ตอนนี้ไม่มีสินค้าชิ้นไหนใช้แล้ว
แต่เก็บไว้เผื่อต้องการรูปแทนชั่วคราวตอนเพิ่มสินค้าใหม่
