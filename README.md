# Grandprix Online — ระบบ e-commerce สินค้าพรีเมี่ยม

ร้านค้าออนไลน์สำหรับสินค้าพรีเมี่ยมของการแข่งขัน Grandprix
พร้อมระบบหลังบ้านสำหรับจัดการแบนเนอร์ สินค้า สมาชิก และดูยอดขาย

🔗 **เว็บไซต์:** https://nidss.github.io/gps/

---

## ⚠️ ข้อควรทราบก่อนใช้งาน

เว็บนี้ deploy เป็น **static site** บน GitHub Pages จึง **ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูลจริง**

- ข้อมูลทั้งหมด (สินค้า ตะกร้า สมาชิก ออเดอร์) เก็บอยู่ใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง
- ข้อมูลไม่ sync ข้ามอุปกรณ์ และจะหายถ้าล้างข้อมูลเบราว์เซอร์
- ระบบล็อกอินและสิทธิ์ผู้ดูแลเป็นการสาธิตระดับ UI เท่านั้น **ไม่ปลอดภัยพอสำหรับใช้งานจริง**
- ถ้าต้องการใช้งานจริง ต้องต่อ backend + ระบบชำระเงินจริง
  (โครงสร้าง state แยกไว้ใน `src/store/AppStore.tsx` เพื่อให้สลับไปเรียก API ได้ไม่ยาก)

## ✨ ฟีเจอร์

### หน้าร้าน

| หน้า | เส้นทาง | รายละเอียด |
|---|---|---|
| หน้าแรก | `#/` | Hero banner เลื่อนอัตโนมัติ + สินค้าแนะนำแบบ grid 4 คอลัมน์ |
| สินค้าทั้งหมด | `#/products` | กรองหมวดหมู่ ค้นหา และเรียงลำดับราคา |
| รายละเอียดสินค้า | `#/product/:id` | แกลเลอรีหลายรูป ราคาลด สต็อก และปุ่มเพิ่มลงตะกร้า |
| ตะกร้าสินค้า | `#/cart` | ปรับจำนวน ลบสินค้า และสรุปยอด |
| ชำระเงิน | `#/checkout` | ที่อยู่จัดส่ง **คูปองส่วนลด** **ออกใบกำกับภาษี** และวิธีชำระเงิน |
| ชำระเงินสำเร็จ | `#/checkout/success/:id` | เลขที่คำสั่งซื้อ สรุปรายการ และข้อมูลใบกำกับภาษี |
| สมัครสมาชิก | `#/register` | ตรวจสอบข้อมูลครบถ้วนและกันอีเมลซ้ำ |
| ข้อมูลส่วนตัว | `#/account` | ข้อมูลติดต่อ · ที่อยู่จัดส่ง · ที่อยู่ออกใบกำกับภาษี · ประวัติสั่งซื้อ |

Navbar มีครบทั้ง **การแจ้งเตือน** (พร้อมตัวนับที่ยังไม่อ่าน) **เมนูสมาชิก** และ **ตะกร้าสินค้า**

## 🛠 เทคโนโลยี

- **Vite 7** + **React 19** + **TypeScript**
- **Tailwind CSS 4** (ชุดสีแบรนด์: `#dd3333` และ `#333946`)
- **React Router 7** แบบ HashRouter — ทำให้รีเฟรชหน้าลึก ๆ บน GitHub Pages ไม่เจอ 404
- ไม่มี dependency สำหรับ UI หรือกราฟ — ไอคอนและกราฟเขียนเป็น SVG เองทั้งหมด

## 🚀 พัฒนาต่อ

```bash
npm install
npm run dev        # เปิด dev server
npm run build      # ตรวจ type แล้ว build ลง dist/
npm run preview    # ดูผล build
```

Deploy อัตโนมัติผ่าน GitHub Actions ทุกครั้งที่ push เข้า `main`
(ดู `.github/workflows/deploy.yml`)

## 📁 โครงสร้างโปรเจกต์

```
public/
  logo-grandprix.png        โลโก้แบรนด์
  images/                   รูปสินค้าและแบนเนอร์ (SVG สร้างจาก scripts/gen-images.mjs)
src/
  types.ts                  ชนิดข้อมูลกลาง
  lib/                      storage, seed, format, orderStatus, asset
  store/AppStore.tsx        state ทั้งหมด + hooks แยกตามหมวด
  components/               Navbar, HeroSlider, ProductCard, AdminLayout, Charts, ui
  pages/                    หน้าฝั่งลูกค้า
  pages/admin/              หน้าระบบหลังบ้าน
```

### เปลี่ยนรูปสินค้าเป็นรูปจริง

รูปสินค้าปัจจุบันเป็น placeholder สีแบรนด์ที่สร้างจาก `scripts/gen-images.mjs`
เปลี่ยนเป็นรูปจริงได้โดยวางไฟล์ทับใน `public/images/products/`
หรือแก้ที่อยู่รูปผ่านหน้า **จัดการสินค้า** ในระบบหลังบ้านได้เลย
